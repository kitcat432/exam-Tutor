# Offline Exam Coach

A local AI exam coach powered by the QVAC SDK.

## Features

- Local on-device AI inference
- QVAC `loadModel` and `completion`
- No cloud AI API required
- Command-line exam coaching

## Requirements

- Node.js 22+
- Windows 10/11 x64
- QVAC-compatible hardware
